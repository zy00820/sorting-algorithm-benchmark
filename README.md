## 研究内容

- 四个对照算法：插入排序、归并排序、堆排序、快速排序；快排为三数取中 + 三路划分 + 小区间插入。
- 四类数据分布：随机排列、近乎有序、完全逆序、含少量乱序；固定随机种子，结果可复现。
- 自适应选择器：只读提取相邻逆序比 r、有序段占比、相邻相等比 dup 三个特征，按规则从候选算法中选择一种执行。
- 内置 `sorted`（Timsort）仅作工业级参照，不作为赶超目标。

## 怎么跑出自己的实测数据

1. 安装 Python 3（无需第三方库，仅用标准库）。
2. Windows 可直接双击 `python/运行.bat`；或进入 `python` 目录运行：

```bash
python benchmark.py
```

3. 运行结束后在项目根目录生成 `results.csv`，即为本课题的原始测试数据；把其中数值回填到《研究报告初稿.docx》第 5 章表格与图表处。
4. 测试规模、重复次数、随机种子在 `data_gen.py` 顶部可调；改动后须在研究日志中记录调整原因。
