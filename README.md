# 排序算法基准测试

课题：多种排序算法在不同数据分布下的实测性能对比研究
学科：计算机科学与信息技术（CS）

## 目录结构

```
├── python/
│   ├── sorts.py          # 四种排序算法（插入/归并/堆/快速排序），带比较、移动次数统计
│   ├── data_gen.py       # 四类数据分布生成（固定随机种子，可复现）
│   ├── selector.py       # 自适应选择器：提取有序度特征，按规则选择候选算法
│   ├── benchmark.py      # 基准测试：计时、计数，导出 results.csv
│   └── README-运行说明.txt
└── docs/
    ├── 研究报告初稿.docx  # 结构完整，实测数据处留占位，待回填
    ├── 研究日志模板.docx # 按日期如实记录研究过程
    ├── 附件材料清单.docx # 对应申报书 C 区第 3 条
    ├── 答辩准备材料.docx # 陈述讲稿、提问参考回答、口径红线与演示流程
    └── results_template.csv # 原始数据表模板（仅表头）
```

## 研究对象

- 四种手写固定算法：插入 / 归并 / 堆 / 快速排序；
- 自适应选择器：先提取相邻逆序比、有序段占比两个特征，再按规则选择候选算法；
- 内置 sorted（Timsort）：工业级自适应排序，仅作参照，不作为赶超目标。

## 运行方法

1. 安装 Python 3.10 以上（仅用标准库，无需安装第三方包）；
2. 进入 `python` 目录，运行：

```bash
python benchmark.py
```

3. 运行结束后生成 `results.csv`，即原始测试数据；将数值回填到 `docs/研究报告初稿.docx` 第 5 章表格与图表处。

## 口径提醒

- 比较次数：两元素发生一次大小比较记 1 次；移动/交换次数统计口径以 sorts.py 为准。
- 排序算法为经典公开算法；本项目创新点在有序度特征驱动的选择策略与对照实测，不要写成“发明了新排序算法”。
- 选择器阈值为初始标定值，需在实测样本上复核并在日志中记录；实测数据须在本人电脑运行脚本获得，不得引用他人设备或虚构数据。
